## 🔧 Development Guidelines

### Adding New Pages
1. Copy the structure from an existing page
2. Update the `<title>` and meta descriptions
3. Ensure navigation active states are correct
4. Follow the established CSS class conventions
5. Test on mobile and desktop

### CSS Best Practices
- Use CSS variables defined in `assets/css/styles.css`
- Follow the BEM methodology for custom components
- Utilize Tailwind CSS classes for layouts and spacing
- Keep custom CSS minimal and purposeful

### JavaScript Guidelines
- All functionality should degrade gracefully
- Use modern ES6+ features with appropriate fallbacks
- Keep the main.js file organized and commented
- Test all interactive features across browsers

### Content Guidelines
- Keep headings semantic (h1 → h2 → h3)
- Use descriptive alt text for images
- Write clear, concise copy focused on benefits
- Ensure all links have descriptive text

## 🚀 Deployment

### Prerequisites
- Modern web server (Apache, Nginx, or similar)
- HTTPS certificate (recommended)
- Domain name configured

### Steps
1. Upload all files to your web server
2. Ensure proper file permissions
3. Test all pages and functionality
4. Set up redirects if needed
5. Configure caching headers for assets

### Performance Optimization
- Compress images before uploading
- Enable Gzip compression on the server
- Set appropriate cache headers
- Consider using a CDN for assets
